## P001 = S1 — Dynamic Trading with Predictable Returns and Transaction Costs

### A. 一页决策摘要

- **paper_id**: P001
- **candidate_status**: CORE
- **title**: Dynamic Trading with Predictable Returns and Transaction Costs
- **one_sentence_problem**: 在收益可被具有不同均值回复速度（alpha 衰减）的信号预测、且交易有成本时，求闭式最优动态组合策略（"aim in front of the target" + 部分向目标交易）。
- **why_replication_is_useful**: 这是"信号衰减—换手—交易成本"联合优化的经典闭式基准；可验证"把慢衰减信号加权更多""动态优于静态/朴素基准"等可量化结论，并作为多信号组合与调仓研究的对照锚点。（建议性表述）
- **main_contribution_in_portfolio_pipeline**: 多期动态调仓路径 + aim portfolio（当前 Markowitz 组合与未来各期预期 Markowitz 组合的加权平均）+ 二次/永久冲击成本下的部分调整规则。
- **recommended_target_scope**: SELECTED_PILOT——(1) 闭式解与理论图（Figure 1–3）可立即忠实实现；(2) Table I 描述统计与 Table II 净夏普需商品期货数据，列为条件性目标；未声明覆盖论文全部稳态均衡含义。
- **proposed_reproduction_type**: INDEPENDENT_FAITHFUL（理论闭式解/图形、以及有数据前提下的 Table II）；若改用公开替代数据重估回归，则单列 APPROXIMATE_VALIDATION。无作者代码，不可做 AUTHOR_CODE_RERUN。

- **strongest_supporting_evidence**: P001-S05（作者官网正式发表版全文，含 Table II 数值与 AQR 署名脚注）；P001-S01/P001-S02（NBER 工作稿披露 AQR 关联与完整实证设定）；P001-S06（勘误 A15）。
- **critical_blockers**: 商品期货历史价格数据与成交量数据的取得权限未确认（P001-B01/B02）；无作者代码（P001-B04）；版本与勘误需锁定（P001-B05）。

### F. 方法与代码尽调

- **decision_variable_and_units**: 动态组合权重/持仓 x_t（美元头寸方向），aim portfolio 为 Markowitz 组合加权平均（P001-S02/S05）
- **inputs**: 当前持仓、信号（5D/1Y/5Y 滚动 Sharpe）、预期收益向量、协方差 Σ、交易成本矩阵 Λ、风险厌恶 γ、贴现率 ρ
- **objective_function**: 二次交易成本 + 永久价格冲击下的多期效用最大化，闭式解（P001-S02 第 II/III 节）
- **constraints**: 预算/自融资；部分调整（updated portfolio = 现有组合与 aim 的线性组合）（P001-S02）
- **outputs**: 最优交易路径、aim portfolio、gross/net 夏普（Table II）、持仓时序（Figure 4）、脉冲响应（Figure 5）
- **risk_and_return_estimation**: Σ 用全样本日价格变化估计、相关性向 0 收缩 50%；收益用 pooled FGLS 回归（P001-S02 式31）
- **hyperparameters_and_selection_rule**: γ=10⁻⁹（约等于 AUM 10 亿美元、相对风险厌恶 1）；ρ=1−exp(−0.02/260)；λ 中位 5.0e−7/均值 8.4e−7；未报告超参数搜索规则（NOT_REPORTED）
- **training_information_set**: 全样本 in-sample（含未来信息用于回归系数），作者明确说明（P001-S02 p.22）
- **random_seed_policy**: NOT_APPLICABLE（确定性闭式解与回归）
- **initialization_and_stopping_rule**: NOT_REPORTED（闭式解无需迭代；数值例见 Figures）
- **portfolio_accounting_equation**: x_{t+1} 为 x_t 与 aim_t 的线性组合（"trade partially toward the current aim"）（P001-S02）
- **turnover_formula**: 交易量随 |x_{t+1}−x_t| 与冲击矩阵决定（二次成本口径）（P001-S02）
- **transaction_cost_and_impact_formula**: Λ=λΣ；短期成本用 Engle, Ferstenberg & Russell (2008) 1.59% 日成交量→0.10% 冲击估计；永久成本 w∈{1,0.5,0} 拆分（P001-S02/S05）
- **financing_cash_and_short_borrow**: 自融资框架；现金/杠杆处理未在实证节单列（NOT_REPORTED）
- **aum_and_risk_targeting**: γ=10⁻⁹ 对应约 10 亿美元 AUM、RRA≈1（P001-S02）
- **metric_definitions_and_annualization**: Table II 为年化夏普，gross（成本前）与 net（成本后）；与朴素基准比较（P001-S05）
